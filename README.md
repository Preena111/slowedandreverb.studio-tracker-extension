# slowedandreverb.studio Tracker Extension

A Chrome extension that tracks your listening time, average pitch, and average reverb on [slowedandreverb.studio](https://slowedandreverb.studio).
It keeps per-song stats and pulls album covers from Last.fm.
To install, open `chrome://extensions`, turn on Developer mode, click **Load unpacked**, and select this folder.
All stats are stored locally in your browser.
